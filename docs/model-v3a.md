# V3-A 模型说明

[返回仓库首页](../README.md) · [实验结果](experiments.md) · [数据管线](data-pipeline.md)

V3-A 是按视觉提示和机器人状态生成**右臂关节目标与夹爪开口**的动作块策略。操作者或上游模块在首帧给一个目标框和一个抓取点。框表示抓哪件物体，点表示抓物体哪个位置。例如固定杯子 BBox，仅把点从杯身移到杯柄，即得到另一项任务。双腕均用当前 RGB。头部 RGB、双腕 RGB 和本体状态每个控制步刷新，首帧框和点在该回合保持固定。

## 输入、输出与单位

下表用 `B` 表示 batch 大小。三张 RGB 的原始分辨率均为 `224×224`。

| 输入 | 模型形状 | 内容 |
| --- | --- | --- |
| 头部图像 | `[B,5,224,224]` | 当前 RGB、首帧 BBox 二值掩码、首帧抓取点高斯热图 |
| 左腕图像 | `[B,3,224,224]` | 当前左腕 RGB |
| 右腕图像 | `[B,3,224,224]` | 当前右腕 RGB |
| 本体状态 | `[B,2,17]` | 上一个 20 Hz 控制步和当前步。每步为右臂 `qpos(7)`、开口 `width(1)`、末端 `XYZ(3) + rotation6D(6)`。第 0 步复制首状态补历史 |
| 提示几何 | `[B,10]` | 框中心、宽高、两个有效性占位值 `[1,0]`、抓取点及其相对框中心偏移。坐标以图片范围归一化 |

外部首帧条件为 `bbox=[x1,y1,x2,y2]` 和 `point=[u,v]`，均为 0 到 1。RGB 按 ImageNet 均值和方差标准化。HDF5 末端姿态按 XYZ 加 `xyzw` 四元数保存，适配层取旋转矩阵的前两列转换成 6D。状态和动作使用训练集统计量标准化，推理从同一个检查点读回统计量。

**输出形状为 `[B,8,8]`**。8 行对应从当前控制步开始的 8 个 20 Hz 动作，时间窗口为 0.4 秒。每行为 7 个绝对关节角目标以及 1 个夹爪目标开口。反归一化后单位依次为 rad 和 m。关节列顺序取 HDF5 的 `meta/joint_names`。执行器负责安全限幅和动作下发，并独立判定抓起结果。

## 网络如何处理三视角与提示

1. 独立的第一层卷积把头部 5 通道、左右腕各 3 通道映射到 64 通道。从 `bn1` 到 `layer3` 共用一套 ResNet-18 参数。第三残差阶段输出每路 `14×14×256` 特征。正式训练从 ImageNet 初始化 RGB 主干，冻结 BN 的运行统计量。
2. 头部框掩码平均池化到 `14×14`，抓取点热图最大池化到同尺寸。两张提示图与头部特征拼成 258 通道，通过 `1×1 Conv(258→256)`、ReLU 和 LayerNorm 融合。保留头部第一层卷积的两张提示通道。
3. 空间网格展平为 **588 个视觉 Token**。每个 Token 加可学习 2D 位置向量和对应相机的可学习 ID 向量。再加 1 个状态 Token 和 1 个提示几何 Token，Transformer 编码器共接收 590 个 Token。
4. 解码器有 8 个动作 Query。框的四角坐标、抓取点二维坐标和二维相对偏移，共 **8 维**，经两层 MLP 映射为 256 维向量，加到全部动作 Query。这样抓取点既参与头部空间特征，也能直接调节动作输出。
5. Transformer 含 2 层编码和 4 层解码，宽度 256、4 头注意力，前馈宽度 1024。线性输出层把每个动作 Query 投影为 8 个目标值。

## 离线试玩与在线控制

已有演示使用同一观测和 BBox，分别在杯身及杯柄上点提示，展示各自的 8 步预测。 [HTML 下载](demos/model-io.html) · [MP4 下载](demos/model-io.mp4)

有真实 HDF5 和终版 V3-A 检查点时，按 [数据导入说明](data-pipeline.md#导入既有清单) 生成可移植清单后，在仓库根运行下列命令。

```bash
python -m pip install -e ".[v3a]"
python examples/predict_v3a.py ./data/tier1.json /path/to/A40/last.pt \
  --data-root /path/to/original --split validation --index 0 --device cpu
```

CLI 输出样本身份、控制步、关节名、单位和 `8×8` 的物理动作。加载器要求终版的五通道头部和三通道右腕口径，以及空间融合、抓取点 Query 和框 Query 开关。项目权重需要从原训练产物取得。

闭环中每步重新预测一个动作块，只执行融合后的当前一步。时序融合模块对仍覆盖当前步的历史预测按指数加权（`m=0.01`），并随回合重置。夹稳后控制权交给统一试提执行器。此接法见 [时序融合](../simulation/isaac_snapshot/temporal_actions.py) 和 [统一执行器](../simulation/isaac_snapshot/unified_grasp.py)。
